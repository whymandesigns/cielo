# Cielo

A full-viewport clock whose face is the sky over you. It reads your location, shows local time, and paints the atmosphere from live weather: sunrise, sunset, clear, cloud, or rain.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL. Allow location if prompted; otherwise the clock falls back to IP-based coordinates. Weather comes from [Open-Meteo](https://open-meteo.com/). Use the chips at the bottom to preview each sky without waiting for the weather to change.
